# 二级供应商后台管理系统本地原型

本目录根据 `supplier-dine-admin-second-ui-master.zip` 中的线上 Vue 后台源码复原，定位为真实仓库构建版本地原型。

## 已复原范围

- 复用线上 Vue / RuoYi / Element Plus 的真实页面结构与样式
- 本地注入登录态，无需真实账号即可进入后台
- 本地预览服务提供演示接口数据，不请求线上业务接口
- 覆盖订单管理、出价管理、品牌账号管理、账户管理、结算主体、导出中心等线上菜单

## 使用方式

双击 `打开二级供应商后台原型.cmd`，然后访问：

`http://127.0.0.1:8775/`

不建议直接双击 `index.html`，因为真实 Vue 后台依赖本地路由和接口服务。
