# 变更记录：小程序筛选项显示规则与后台横向滚动三次修复

## 修改时间
2026-09-15

## 问题
- 小程序补偿单列表中，非“全部”tab 不应展示“商品品牌”筛选项。
- 点餐后台开票订单页的自定义横向滑杆不好用，点击后会闪一下，无法稳定滑动。

## 本次修复
- 小程序筛选弹窗改为按 tab 动态展示筛选项：
  - “全部”tab：展示“商品品牌”筛选项。
  - “瑞幸咖啡 / 肯德基 / 麦当劳”tab：不展示“商品品牌”筛选项。
- 非“全部”tab 打开筛选弹窗时，自动将商品品牌筛选恢复为“全部品牌”，避免隐藏卡片。
- 点餐后台开票订单页删除自定义 range 滑杆。
- 点餐后台开票订单页保留表格底部原生横向滚动条，并增加提示“左右拖动表格底部滚动条查看全部字段”。
- 表格同一 tab 下不再反复重建，避免点击或拖动时闪烁、滚动位置被重置。

## 自检结果
- 小程序已验证：
  - “全部”tab 有“商品品牌”筛选项。
  - “瑞幸咖啡 / 肯德基 / 麦当劳”tab 均无“商品品牌”筛选项。
- 点餐后台已验证：
  - 自定义 range 滑杆已移除。
  - 表格横向滚动容器仍存在，表格宽度大于容器宽度。
  - 等待自动刷新后，表格不再被反复重建。
- 两个脚本已通过语法校验。
