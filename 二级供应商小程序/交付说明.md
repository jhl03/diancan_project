## 二、页面与功能清单

### 1. 登录 / 注册
- 登录方式选择页：手机号快捷登录、账号密码登录；未勾选隐私政策拦截登录
- 账号密码登录：所属供应商（必填，需与账号配对，不符提示“所属供应商不对，请重新选择”）、账号限 11 位、密码可见切换、登录按钮未填完置灰
- 注册供应商页：所属供应商枚举、主体类型（个人/个体户/公司，切换联动附加字段）、手机验证码 60s 倒计时、合作品牌多选、推荐人手机号、身份证上传（微信风格操作菜单）

### 2. 首页（底部 Tab 1）
- 顶部按商品名称搜索 + 筛选弹窗（商品品牌 / 报价规则 / 出餐方式 / 状态，支持重置）
- 报价规则卡片：启用/禁用二次确认、修改自动回填、删除二次确认
- 底部「＋ 新增报价规则」
- 新增/修改报价规则页：商品品牌必选、商品表格（报价限价只读，取后台配置）、报价金额校验（>0 且不高于最低报价限价）、出餐方式、出餐城市、套餐模式与编号

### 3. 工作台（底部 Tab 2）
- 品牌账号区：瑞幸账号、瑞幸兑换券
- 待处理订单区：竞价记录
- 其他区：设置

**瑞幸账号**：启用/禁用双 Tab（状态显示“启用（已登录）”“禁用（已登录）”，绿色 / 橙色）；新增账号弹窗（账号限 11 位、验证码、限定城市、每日最高单量限 8 位）；卡片操作：拉取更新、登录（验证码 60s）、禁用/启用（二次确认）、设置（展开限定城市 / 最高单量）

**瑞幸兑换券**：普通卡 / 全家福 × 未使用 / 已使用 / 全部；券卡片明细（券名 / 券码 / 失效时间 / 券状态 / 成本价 / 可兑换商品）；全选与“已选择 N 项”联动
- 设置成本价 → “设置成本价格”弹窗（当前选中 N 张券、成本价输入 + 元、参考说明文案）
- 设置可兑换商品 → 底部半屏弹层（关键词搜索、“已选中 N 件商品”、商品列表勾选）

**竞价记录**：竞价成功 / 竞价失败双 Tab；成功卡片可复制竞价信息；失败卡片含失败时间、未选中原因、成交价；筛选弹窗（商品品牌 + 竞价时间区间）

### 4. 订单（底部 Tab 3）
- 五个状态 Tab：新订单 / 已报价 / 待出单 / 已完成 / 全部
- 新订单：报价卡片（门店名“商品品牌(店铺名)”+ 绿色复制按钮 + 倒计时 + 订单明细 + 报价金额输入与「报价」按钮，报价成功转入已报价）
- 已报价：展示报价编码与报价金额（红色）；「修改报价金额」底部弹窗（同步修改原报价规则提示、原报价金额、最高限价）
- 待出单：超时出餐倒计时；「人工出餐」（手机尾数 4 位 + 取餐码校验）、「取消出餐」（原因 0/50 字数校验）
- 非新订单 Tab 时出现新订单提醒条（“又有 2 笔新订单了，请到新订单页面查看”），切到新订单即消失

### 5. 我的（底部 Tab 4）
- 头像与姓名、账户余额（3.52 元）
- 退出登录二次确认弹窗

### 6. 辅助功能
- 原型右侧外置面板：左侧功能索引（点击直达任意页面/弹窗）、右侧页面说明（分点展示；首页/工作台/订单/新增报价规则页带高亮提示）
- “我的”页提现入口及提现相关页面已隐藏（对应索引项置灰）
