# 点餐代理供应商系统 · 双击打开版

## 这是什么

把整个「二级供应商后台管理系统」原型压缩成了**一个 HTML 文件**：
`点餐代理供应商系统-双击打开.html`（约 5.24 MB）。

**双击它就能直接在浏览器里看到完整系统原型**，不需要：
- ❌ 双击 `.cmd` 启动预览服务器
- ❌ 本地 Node / Python 环境
- ❌ 上传 GitHub Pages
- ❌ 联网（完全离线可用）

## 使用方式

1. 双击 `点餐代理供应商系统-双击打开.html`（推荐 Chrome / Edge 浏览器）
2. 直接浏览。三个改动页入口在左侧菜单：
   - 订单管理 → **补偿单列表**
   - 订单管理 → **售后补贴单**
   - 账户管理 → **结算记录**
3. 其余菜单（新订单、订单列表、竞价记录等）为原生页面，可正常切换。

> 发给别人时**只需要发这一个文件**，微信/邮件传过去对方双击即可看。

## 技术原理（为什么能做到单文件）

`file://` 协议下浏览器会拦截 ES Module（CORS 限制），所以之前必须起本地服务器。
本版本的解决方式是**不改变原构建产物的模块语义**，只换资源加载方式：

| 改造点 | 做法 |
|---|---|
| JS 模块 | 全部 36 个 chunk 原样转成 blob URL，通过 `<script type="importmap">` 把 `./assets/xxx.js` 映射过去，保留原生 `import()` 语义 |
| CSS | 23 个样式表全部内联成 `<style>` |
| 图片 / favicon | 转成 data URI 内联 |
| 演示接口 | `prototype-api.js` 劫持 XHR/fetch，浏览器内返回演示数据，无需后端 |
| 路由 | vue-router base 适配为当前文件路径；`history.pushState` 在 file:// 下的异常做了兜底 |
| 注入脚本 | 「补偿单列表 / 售后补贴单 / 结算记录」三个改动页的渲染逻辑原样保留，导航改为内存路由 + 按需重载 |

## 已知限制

- 首次打开需加载约 5 MB 内容，低配电脑上侧栏出现前可能有 1–2 秒空白，属正常。
- 页面切换中「原生页 ↔ 改动页」之间会整页刷新一次（约 1 秒），改动页之间切换是即时的。
- 刷新页面会回到上次浏览的页面（记录在浏览器 sessionStorage 中）。
- 仅推荐 Chrome / Edge 等现代浏览器；不支持 IE。
