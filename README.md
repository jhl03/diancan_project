# 点餐C端开票二期 GitPages 交付包

本包用于上传到 Git 仓库后通过仓库 Pages 链接直接打开原型页面。

## 包含系统

- 供应商后台系统：`供应商后台系统/`
- 供应商小程序：`供应商小程序/`
- 点餐后台系统：`点餐后台系统/`
- 汇总入口页：`index.html`
- 变更记录：`变更记录/`

## 仓库访问链接格式

开启 Pages 后，假设仓库 Pages 根地址为：

```text
https://<用户名>.github.io/<仓库名>/
```

则可访问：

```text
https://<用户名>.github.io/<仓库名>/index.html
https://<用户名>.github.io/<仓库名>/供应商后台系统/
https://<用户名>.github.io/<仓库名>/供应商小程序/
https://<用户名>.github.io/<仓库名>/点餐后台系统/
```

Gitee Pages、GitLab Pages 或企业内部静态站点同理，把根地址替换成对应仓库页面地址即可。

## 与本地预览包的区别

旧交付包主要面向本地预览服务，页面资源使用根路径加载。这个版本已把页面入口和静态资源改为相对路径，适合放在仓库子目录中通过 Pages 打开。

## 本地查看方式

不要直接双击三个系统目录里的 `index.html`，浏览器用 `file://` 打开打包页面时可能一直停留在“正在加载系统资源”。

本地检查请双击：

```text
一键本地预览.cmd
```

启动后会自动打开：

```text
http://127.0.0.1:8798/index.html
```

再从入口页进入供应商后台系统、供应商小程序、点餐后台系统。
