订单管理 - 订单列表

新订单提示：
待出单订单提醒开关：
🔊 又有2笔新订单了，戳我立即刷新~

说明

新增范围包括：一级供应商后台。挂有二级的一级供应商后台不能显示操作列的内容

新订单页面、已报价页面的数据是实时推送的【小程序的也是一样的】

页面的流转：未报价的订单在新订单页面，报价后直接进入已报价页面，倒计时继续，如果报价后倒计时结束直接进入待出单页面【不再进入已报价页面了】。

待出单订单提醒开关：页面右上角显示“待出单订单提醒开关：”开关图标，默认开启；逻辑为“待出单中若有待出餐订单时，新订单即使开启也不进行提醒”。有待出餐订单进入时，网站右上角显示通知“待出餐提醒，请及时处理”，左侧带音量图标，右侧带删除图标；语音响起时显示，持续 2s 后自动消失，也可点击删除图标手动关闭。关闭提示音后不再显示待出餐语音提醒。

新订单提示音开关：页面右上角显示“新订单提示：”开关图标，默认开启；点击开关切换时使用轻提示“提示音已开启 / 提示音已关闭”。

右上角语音提醒：有新订单进入时，网站右上角显示通知“守兔来新订单啦”，左侧带音量图标，右侧带删除图标；语音响起时显示，持续 2s 后自动消失，也可点击删除图标手动关闭。关闭提示音后不再显示新的语音提醒。

站内新订单提醒：订单列表页面标题与筛选区之间显示红色提醒条“又有N笔新订单了，戳我立即刷新~”；点击提醒条后刷新订单列表并隐藏提醒条。若“新订单提示”开启，同时会有右上角语音提醒。

页面定位：供应商端【PC】 > 订单管理 > 订单列表，用于展示供应商的出餐订单，按“新订单/已报价/待出单/已完成/已失败/全部”切换 tab。

新订单 tab：展示所有下单成功但尚未报价的订单。【新增的tab】

已报价 tab：展示所有已报价、正在参与竞价的订单，字段与「新订单」tab 保持一致。【新增的tab】

原tab名称“进行中”改为“待出单” 【小程序也是一样的】

列表排序：「新订单」与「已报价」tab 均根据倒计时排序，短的在上面。

待出单角标：「待出单」tab 右上角红字角标显示待出单订单数量，数量为 0 时隐藏。

筛选项输入框逻辑：

筛选项：筛选项与系统原来的筛选项一致。

出餐单号：支持按出餐单号精确查询。若在新订单、已报价页面搜索某些列表没有的字段，搜索之后，列表显示“暂无数据”。

列表字段的数据源与显示逻辑：

新订单列表数据源：展示所有下单成功但尚未报价的订单（无报价金额）。

已报价列表数据源：展示所有已报价的订单，包括新订单页面报价后的订单【新订单页面进入的出餐方式默认手动，报价金额按照新订单页面输入的报价金额、报价规则显示“-”】其他字段与新订单页面的字段值是一样的。

待出单列表数据源：待出单页面列表的字段与已出单页面列表的字段是一样的。

列表字段排序：报价编码、商品品牌、商品名称、商品SKU、报价倒计时/竞价倒计时、门店名称、店铺地址、市场价、最高限价、报价金额、报价规则。

报价编码：取数据库已有的报价编码。

商品品牌：取当前订单的商品品牌。

商品名称：取当前订单的商品名称；若同一订单包含多个商品名称，换行显示，全部展示。

商品SKU：取当前订单的商品规格，具体展示如“默认浓度/无奶油/冰/标准甜/意式拼配/大杯”。

报价倒计时/竞价倒计时：均取后台配置的“订单分配前倒计时”，按 HH:mm:ss 格式展示；新订单 tab 列头显示“报价倒计时”，已报价 tab 列头显示“竞价倒计时”。倒计时结束，系统按照报价最低的供应商进行订单分配。

门店名称：取该订单对应门店的展示名称。

店铺地址：取对应门店地址，过长时允许自动换行。

市场价：取后台配置的商品原价。

最高限价：取后台配置的最高限价。

报价金额：命中已经配置的报价规则取规则配置的报价金额【若有重复取最优的】；新订单页面的报价金额显示“-”。

报价规则：命中报价规则时显示当前命中的报价规则名称；新订单页面进入到已报价页面的订单显示“-”。

出餐方式：仅已报价 tab 展示，取当前订单的出餐方式，如“人工”“自动”。

操作：新订单 tab 仅当出餐方式为“人工”时展示行内报价输入框与“报价”按钮，否则操作列显示“-”；已报价 tab 仅当出餐方式为“人工”时显示“修改报价”按钮（包括新订单页面进入已报价页面的订单），否则显示“-”。

行内报价输入框：新订单 tab 操作列内展示，用于输入当前订单的报价金额。

报价按钮：点击后校验：① 报价倒计时已结束时提示“报价倒计时结束，不能添加报价”；② 报价金额必填，为空提示“请填写报价金额”；③ 报价金额必须为数字且不能为 0；④ 报价金额不能大于该商品最高限价；⑤ 报价金额小数位数按后台配置的“供应商报价金额保留小数”生效；⑥ 点击按钮，校验该商品是否已经存在报价规则；若存在提示“该商品已存在报价规则，在已报价页面查看”；⑦ 点击按钮时，校验是否被限制报价权限，若限制提示“您因订单超时未处理已被限制报价权限，具体信息查看公众号”。

修改报价：已报价状态（出餐方式为“人工”）点击“修改报价”按钮后弹出「修改报价」弹窗，弹窗内容如下：

原报价金额：取列表对应的报价金额，只读展示。

新报价：输入框，限制与新增/修改报价金额输入框一致（必填、必须为数字且不为 0、不能大于最高限价、小数位数按后台“供应商报价金额保留小数”生效）。

最高限价：取列表对应的最高限价，只读展示。

规则同步：在商品报价页面已有的规则，修改后的金额会同步到已有的规则里面。

命中规则提示：当该报价规则命中商品报价页面的规则时，原报价金额右侧显示“（该报价金额来自商品报价规则页面）”。

订单管理 - 竞价记录

说明

新增范围包括：一级供应商后台。挂有二级的一级供应商后台不能显示操作列的内容

页面定位：供应商端【PC】 > 订单管理 > 竞价记录，用于展示供应商参与竞价的订单，按「竞价失败」「竞价成功」两个 tab 切换查看。

竞价记录包括：所有的出餐方式【人工、自动…】

竞价记录页面数据源：
例：第一轮：有A、B、C三个供应商竞价，A竞价成功，出餐失败，B、C竞价失败；
第二轮：有B、C、D、E四个供应商竞价，B竞价成功，出餐成功，C、D、E竞价失败；
以此类推，注意，最后竞价记录是A、B竞价成功，C、D、E竞价失败

竞价失败原因：
1. 超出接单配置时，原因为：超过最大接单数量
2. 比价失败时，原因为：报价金额不是最低
3. 价格相同随机分配时，原因为：订单价格相同，供应商随机分配，未被选中
4. 触发兜底规则时原因为：因订单流转超时，已自动指派兜底供应商----出餐方式为自动 / 超过最大接单数量----出餐方式为人工

竞价失败原因显示逻辑：

1. 竞价记录页面：
  1.1 流转过程中，有供应商竞价成功，其他竞价失败的情况如下：
    1.1.1 成交价【取中标供应商的报价，若配置了保留一位小数，报价舍掉第二位小数】 = 供应商报价，
            竞价原因：订单价格相同，供应商随机分配，未被选中 / 超过最大接单数量
    1.1.2 成交价【取中标供应商的报价，若配置了保留一位小数，报价舍掉第二位小数】 ＜ 供应商报价，
            竞价原因：报价金额不是最低
    1.1.3 成交价【取中标供应商的报价，若配置了保留一位小数，报价舍掉第二位小数】 ＞ 供应商报价，
            竞价原因：因订单流转超时，已自动指派兜底供应商----出餐方式为自动 / 超过最大接单数量----出餐方式为人工

  1.2 流转过程中，没有供应商竞价成功，其他竞价失败的情况如下：
    前提：竞价失败页面 成交价取竞价表里面最低的
    1.2.1 成交价【取竞价表里面最低价，若配置了保留一位小数，报价舍掉第二位小数】 = 供应商报价，
            竞价原因：订单价格相同，供应商随机分配，未被选中
    1.2.2 成交价【取竞价表里面最低价，若配置了保留一位小数，报价舍掉第二位小数】 ＜ 供应商报价，
            竞价原因：报价金额不是最低

  1.3 流转过程中，有供应商竞价成功，但是没有出餐超过的，其他竞价失败的情况如下：
    前提：竞价失败页面 成交价取接单记录里面报价金额最低的
    1.3.1 成交价【取接单记录里面报价最低，若配置了保留一位小数，报价舍掉第二位小数】 = 供应商报价，
            竞价原因：订单价格相同，供应商随机分配，未被选中
    1.3.2 成交价【取接单记录里面报价最低，若配置了保留一位小数，报价舍掉第二位小数】 ＜ 供应商报价，
            竞价原因：报价金额不是最低

字段口径：竞价记录页面展示商品名称、商品品牌、门店名称、店铺地址、市场价、报价金额、报价规则名称、竞价成功时间、竞价失败原因、竞价失败时间和操作；其中成交价仅在竞价失败 tab 列表展示。

筛选项输入框逻辑：

商品名称：支持按商品名称关键词下拉检索。

商品品牌：支持按品牌名称下拉检索。

竞价时间：按开始时间和结束时间做区间筛选。

搜索：按当前输入条件组合查询。

清空：恢复为空条件。

导出按钮：「搜索」「清空」按钮后方提供「导出」按钮，点击后导出当前 tab 列表所有内容（不含操作列）为 CSV 文件。异步导出

列表字段的数据源与显示逻辑：

列表数据源：取当前供应商所有报价商品中，对应竞价状态的出餐订单。

商品名称：取当前竞价记录订单的商品名称。

商品品牌：取当前竞价记录订单的商品品牌。

门店名称：取该订单对应门店的展示名称。

店铺地址：取对应门店地址，过长时允许自动换行。

市场价：取后台配置的商品原价。

报价金额：取该供应商本次参与竞价时的报价。

成交价：在竞价失败原因显示逻辑里面查看具体取值。

成交价小数规则：若报价金额配置了保留一位小数时，成交价的金额也保留一位小数，取数规则【舍掉第二位及之后的小数】。

报价规则名称：取当前命中的报价规则名称。

竞价成功时间：仅竞价成功 tab 展示实际成功时间，列表按该时间倒序；竞价失败 tab 不展示该字段。

竞价失败原因：仅竞价失败 tab 展示具体原因；竞价成功 tab 不展示该字段。

竞价失败时间：仅竞价失败 tab 展示实际失败时间，列表按该时间倒序；竞价成功 tab 不展示该字段。

操作：竞价失败 tab 展示“修改报价金额”按钮；新订单页面报价的商品不显示“修改报价金额”按钮；竞价成功 tab 操作列不展示按钮，且最后一列不固定。

编辑报价规则页面：点击“编辑报价金额”后进入「编辑报价规则」页面，内容与供应商后台的商品报价页面的修改报价规则弹窗内容一致。点击“确定”后保存结果同步到出价管理--商品报价页面、点餐后台--商品报价页面、一级供应商的出餐管理--商品报价页面，以及对应的小程序端。

出价管理 - 可报价商品列表

商品图片 商品名称 商品品牌 成交价 商品类型 更新时间

说明

新增页面范围包括：一级供应商后台。

页面定位：供应商端【PC】 > 出价管理 > 可报价商品列表，用于展示供应商当前可报价的商品范围。

列表数据源：只显示点餐后台--商品列表的商品状态上架、平台销售状态上架的商品。

更新规则：定时更新【每天凌晨2点更新数据】，可点击按钮 手动更新【要注意防抖】。

筛选项输入框逻辑：

商品名称：支持按商品名称关键词下拉检索。

商品品牌：支持按品牌名称下拉检索。

更新时间：按开始时间和结束时间做区间筛选。

搜索：按当前输入条件组合查询。

清空：恢复为空条件。

手动更新：点击后实时拉取后台商品数据；5 分钟内重复点击，页面上方轻提示“5分钟后再点击”；成功后页面上方轻提示“更新成功”。

列表字段的数据源与显示逻辑：

商品图片：取商品主图，无图片时展示默认占位图。

商品名称：取后台商品名称。

商品品牌：取后台商品品牌。

成交价：取当前商品截止更新时的出餐成功的结算价；若没有出餐取后台的最高限价。

商品类型：取后台对应商品的类型。

更新时间：取每次更新的时间【包括手动/自动】。

说明

Tab 文案：小程序端订单列表按“新订单/已报价/待出单/已完成/全部”切换 tab。

新订单：展示下单成功但尚未报价的订单，卡片头部显示门店、复制按钮、红色报价倒计时；正文展示商品名称、商品品牌、市场价、最高限价、报价金额、报价规则名称；底部为行内报价输入框+“报价”按钮。【新增的tab】

生效含义：输入框为 0 时表示不关闭报价权限；大于 0 时，系统按照对应次数的人工出餐超时未处理状态，暂停供应商对应时长的报价权限。每次系统自动关闭报价权限，都会进行公众号提醒。

注意：
1. 对所有超时未处理的人工报价状态开启的系统自动关闭，到达配置的关闭报价时间后，【每一次系统的自动关闭都会进行公众号提醒】
2. 第三次开启后，如果第四次还是超时未处理，【中间没有出餐成功的情况下】，按照时间停止报价时间最长的生效；若有一次出餐成功，在超时未处理，从第一个设置的开始停止报价配置生效。配置有效时间是当天，过了当天解除不能开启报价状态/新增报价状态的限制
3. 系统自动报价关闭后，未到解除报价权限的时间
4. 若第一个关闭报价时长设置 5 分钟，第二次关闭 10 分钟，在第一次关闭时间时间内，第二个订单也超时未处理，那么，按照当前时间加上第二次的关闭时长作为整个关闭时长，过了这个关闭时长人工可以操作开启报价权限
5. 若被限制报价权限后，点击新增规则按钮/修改规则按钮/开启报价权限/新订单tab的报价按钮，都会提示“您因订单超时未处理已被限制报价权限，具体信息查看公众号”
